# November 2026 roadmap review

Reviewed: 2026-11-05

## Material changes incorporated

- GitHub Agentic Workflows reached GA, so the roadmap pulls a small read-only CI-investigation workflow forward rather than waiting until the later orchestration phase.
- Copilot Fusion reached GA; it is treated as something to benchmark against fixed-model coding agents, not a reason to build a custom general coding-model router.
- Experimental local routing through OpenAI-compatible endpoints makes the GX10 more directly usable from existing coding-agent surfaces, while preserving an independent privacy-aware local gateway because routing itself can still involve cloud infrastructure.
- Recent practitioner reports reinforce that agent throughput makes source control, CI, isolation and integration/review capacity the limiting resources.

## Deliberately unchanged

- No new AI subscription is required.
- No wholesale Kubernetes migration.
- No custom multi-agent UI.
- No additional inference hardware.
- The core sequence remains harness → evals → capability boundaries → durable automation → personal systems → local AI → observability → bounded orchestration → search → rebuildable infrastructure.

This note records the evidence review separately from the interactive roadmap so future pull requests remain auditable.
