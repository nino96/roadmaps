Operating model

Your default engineering rules

Cloud vs localUse Claude Code / Codex / Copilot for interactive coding leverage. Use local models for private, repeatable service workloads only after they pass your eval threshold.
Agent vs codeDeterministic code owns validation, permissions, side effects and known transformations. Models own ambiguity, classification, synthesis and planning.
Compose vs KubernetesCompose first for single-host stateful services. K3s/Flux only after you can state the operational problem it solves.
AutonomyRead/search/triage can be highly automated. Writes use intent → validation → approval where consequential → deterministic execution.
DependenciesPin runtime/tool versions and model revisions. Changes flow through smoke tests + evals + rollback evidence.
SecretsSOPS/age or equivalent encrypted configuration; keys stay out of Git. Agents receive capability-scoped credentials, not your whole vault.
ObservabilityOpenTelemetry first. Trace model/tool steps; default to metadata rather than storing sensitive prompt/document content.
Definition of doneRebuildable, tested, observable, backed up if stateful, documented teardown/restore, and measurably useful.
